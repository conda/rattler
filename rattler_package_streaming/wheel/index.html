Module wheel 

Source
Expand description

Converts wheels into conda cache entries using channel-provided metadata.

Libraries go into site-packages/, scripts into python-scripts/, headers into include/, and data into the package root. The conda linker handles noarch path remapping and entry points from the generated info/link.json. Headers retain conda-pypi’s include/ mapping; pip’s Python-version-specific header paths depend on the target environment, which is unknown during caching. Declared license files are also copied into info/licenses/ (CEP 34). Raw #!python and #!pythonw scripts use relocatable shebangs targeting bin/python on Unix. Windows launchers for raw scripts are not generated.

RECORD describes the cache layout, not final installed paths; its original signatures are discarded. Original RECORD hashes are not verified; callers should verify the returned archive hashes against trusted repodata when available.
