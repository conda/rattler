Struct PackageArchive

pub struct PackageArchive { /* private fields */ }

A conda package archive that can be opened once and read many times.

Cloning is cheap; clones share the parsed archive index and (for spooled archives) the temporary file.

pub async fn read_file( &self, path: impl AsRef<Path>, ) -> Result<Option<Vec<u8>>, ExtractError>

Reads a single file from the package, or None if the path does not exist.

Contents are not cached: every call streams the containing section again up to the requested file. Prefer PackageArchive::read_files with one batch over repeated calls. Requesting a path that is a symbolic or hard link is an error; links are not followed.

match archive.read_file("info/recipe/meta.yaml").await.unwrap() {
    Some(bytes) => println!("recipe: {}", String::from_utf8_lossy(&bytes)),
    None => println!("package has no recipe"),
}
Source

pub async fn read_files( &self, paths: impl IntoIterator<Item = impl Into<PathBuf>>, ) -> Result<HashMap<PathBuf, Option<Vec<u8>>>, ExtractError>

Reads multiple files in one pass per touched section (sections are fetched concurrently), aborting each stream after its last requested file. Maps every requested path to its contents, or None when absent.

Calls are independent and may run concurrently, but contents are not cached: a repeated call streams its sections again, so batch all needed paths into a single call where possible. Requesting a path that is a symbolic or hard link is an error; links are not followed.

// One pass over the payload, one over info, fetched concurrently.
let files = archive
    .read_files(["info/index.json", "lib/libfoo.so", "bin/foo"])
    .await
    .unwrap();
for (path, contents) in &files {
    match contents {
        Some(bytes) => println!("{}: {} bytes", path.display(), bytes.len()),
        None => println!("{}: not in archive", path.display()),
    }
}

pub async fn list_files( &self, section: Section, ) -> Result<Vec<PathBuf>, ExtractError>

Lists the paths of all files (including symbolic links) in one section.

For Section::Info this is usually served from the cached archive tail without extra requests. For Section::Content it streams the entire section; prefer reading info/paths.json when only paths are needed.

use rattler_package_streaming::archive::Section;

// Usually free: the info section tends to sit in the cached tail.
for path in archive.list_files(Section::Info).await.unwrap() {
    println!("{}", path.display());
}

pub async fn stream( &self, section: Section, ) -> Result<SectionStream, ExtractError>

Streams the tar entries of one section. Unread entries are skipped cheaply; dropping the stream aborts any underlying HTTP transfer.

Every call opens a new independent forward-only stream (for remote archives: a new request).

use rattler_package_streaming::archive::Section;

let mut stream = archive.stream(Section::Content).await.unwrap();
while let Some(mut entry) = stream.next_entry().await.unwrap() {
    let path = entry.path().to_owned();
    if path.extension().is_some_and(|ext| ext == "so") {
        let bytes = entry.read().await.unwrap();
        println!("{}: {} bytes", path.display(), bytes.len());
    } // entries that are not read are skipped cheaply
}
