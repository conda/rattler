Expand description

Builds a RepoDataRecord directly from a local .conda or .tar.bz2 package file, without requiring a channel or repodata.json.

The resulting record can be passed straight into Installer::install; the installer already fetches file:// records directly from disk instead of downloading them.

§Example

use rattler_package_streaming::fs::repodata_record_from_package_archive;

let record = repodata_record_from_package_archive("/path/to/local/package.conda")
    .await
    .unwrap();
