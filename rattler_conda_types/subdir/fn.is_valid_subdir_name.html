pub fn is_valid_subdir_name(s: &str) -> bool
Expand description

Returns whether s is a syntactically valid subdir name according to CEP 26: either the literal noarch, or {os}-{arch} where both parts consist of lowercase ASCII letters and digits. The name must not exceed 32 characters.
