pub fn prj_file_name_compare(a: &str, b: &str) -> Ordering

Compare two file names using PrjFileNameCompare semantics: a case-insensitive, ordinal comparison over upper-cased UTF-16 code units.

This is the ordering ProjFS requires for directory-enumeration results. See the module docs for the precise semantics and the known divergences from the real Win32 API.
