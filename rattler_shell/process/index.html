Running a child process within a time and an output bound.

Both the detector executable and the shell that activates its environment run through run_bounded: the clock starts when the process was spawned, standard output and standard error are read concurrently against one combined byte budget, and when either bound is reached the process and its descendants are terminated. Standard error captured until then is kept for diagnostics.
