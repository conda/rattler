Expand description

Like set_exclude_newer, and writes the edit into document, the root table of the configuration file that exclude_newer is loaded from, keeping the comments and layout of the rest of it:

  • A cutoff without exemptions, e.g. exclude-newer = "7d", is expanded into an inline table when a key inside it is edited.
  • Exemptions are matched by their normalized package name. Unlike ConfigBase::set, an exemption keeps the name as it is written in the document, e.g. setting exemptions.Ruff replaces the value of ruff.
  • An exemption that consists of a version spec only, e.g. ruff = ">=0.5", is expanded into an inline table when a field of it is edited.
  • Without exemptions, an inline exclude-newer is written as its cutoff alone, so removing the last exemption leaves e.g. exclude-newer = "7d". A [exclude-newer] table is kept with only its cutoff, keeping its comments.

Returns whether exclude_newer changed. The document is only written if it did.
