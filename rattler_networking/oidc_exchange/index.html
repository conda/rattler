Module oidc_exchange 

Source
Expand description

Exchange of a CI provider’s OIDC ID token for a bearer token.

  1. Ask ambient-id for an OIDC ID token with the configured audience claim (None outside supported CI providers).
  2. Exchange it at the server (see ExchangeProtocol) for a short-lived bearer token.

Used by rattler auth login --workload-identity and, through crate::trusted_publishing, for trusted publishing to prefix.dev.
