Module report 

Source
Expand description

The report a detector writes to standard output, and the contract it must keep with its registration.

A report is exactly one JSON object. It names every virtual package the registration declared, and no other, mapping each to null for absence or to an object with a version and an optional build string. An optional cache object carries hints on how long the result stays valid. Any violation makes the whole report malformed; a client then discards every result of the detector.
