Module detect 

Source
Expand description

Detecting virtual packages with registered detectors, end to end.

For every accepted registration, detect reads the override variables of its names, decides whether the detector has to run at all, resolves it, asks the consent policy, installs and runs it, checks the report, caches the result and collects what the solve should see. A detector’s failure never aborts detection: all of that detector’s results are discarded and the failure is reported alongside the results of the others.
