# c-rattler

C bindings to [rattler](https://github.com/conda/rattler), built with
[cargo-c](https://github.com/lu-zero/cargo-c).

The build produces `librattler` (shared and static), the header
`rattler/rattler.h` and a `rattler.pc` pkg-config file.

> [!WARNING]
> The C API is experimental. Expect breaking changes between `0.x` releases.
> The shared library's soname contains the major and minor version (e.g.
> `librattler.so.0.1`).

## Building

```shell
# with pixi
pixi run install   # installs into target/capi-prefix

# or directly with cargo-c
cargo install cargo-c
cargo cinstall --release --prefix=/usr/local
```

### TLS backend

Select the TLS backend with the `rustls` (default) or `native-tls` cargo
features, e.g. `cargo cinstall --no-default-features --features native-tls`.
The current API does not do any network IO, so the features have no effect
yet. They exist so packaging recipes can already pick a backend.

## Usage

```c
#include <rattler.h>
#include <stdio.h>
#include <string.h>

int main(void) {
    const char *s = "numpy >=1.20,<2";
    RattlerMatchSpec *spec = NULL;
    if (rattler_match_spec_parse(s, strlen(s), RATTLER_PARSE_STRICTNESS_STRICT, &spec) != RATTLER_STATUS_OK) {
        RattlerStr err = rattler_take_last_error();
        fprintf(stderr, "error: %s\n", err.data);
        rattler_str_free(err);
        return 1;
    }

    RattlerVersion *version = NULL;
    rattler_version_parse("1.26.4", 6, &version);
    printf("matches: %d\n", rattler_match_spec_matches_version(spec, version));

    rattler_version_free(version);
    rattler_match_spec_free(spec);
    return 0;
}
```

```shell
cc example.c $(pkg-config --cflags --libs rattler) -o example
```

## API conventions

- Rattler objects are opaque pointers (`RattlerVersion*`, `RattlerMatchSpec*`).
  Every object you receive must be released with its `*_free` function.
  Passing `NULL` to a `*_free` function does nothing.
- Input strings are passed as a pointer and a byte length. They must be valid
  UTF-8 and do not need to be NUL-terminated.
- Output strings are `RattlerStr` values (`data` + `len`, also
  NUL-terminated). Release them with `rattler_str_free`. A `RattlerStr` with
  `data == NULL` means "no value".
- Fallible functions return a `RattlerStatus` and write their result to an
  out-parameter. On failure, `rattler_take_last_error()` returns the error
  message for the calling thread.
- Rust panics never unwind into C. Fallible functions report them as
  `RATTLER_STATUS_PANIC`; infallible functions abort the process.

## Development

```shell
pixi run test             # Rust tests + C smoke test (unix)
pixi run lint
pixi run generate-header  # regenerate include/rattler/rattler.h
```

`include/rattler/rattler.h` is generated by cbindgen and checked in.
`cargo test` fails if it is out of date.
