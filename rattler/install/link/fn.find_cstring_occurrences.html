Finds the c-strings that search-based binary replacement patches, under every encoding the draft CEP defines and ordered by position in the file.

This exposes the search copy_and_replace_cstring_placeholder performs, including how it resolves overlapping candidates of different encodings, so that callers patching files lazily, such as the mount-time ranged reads in rattler_vfs, stay byte-identical with it.
