3//! Read and write [CEP-37](https://github.com/conda/ceps/blob/main/cep-0037.md)
4//! `conda-lock.yml` files.
5//!
6//! [`LockFile`] is the editable format model. [`Document`] additionally retains
7//! the original YAML and source locations for validation and conversion errors.
8//! Reading accepts documented historical conda-lock representations; writing
9//! emits deterministic version-1 YAML without preserving comments or formatting.
10//!
11//! This crate does not solve environments, download artifacts, expand environment
12//! variables, or read source files listed in lockfile metadata. Pixi conversions
13//! are provided by `rattler_lock::conda_lock`.
14//!
15//! Enable the `miette` feature to render [`Error`] labels as source snippets.
16//!
17//! # Compatibility
18//!
19//! Besides the CEP-37 schema, reading accepts the spellings conda-lock itself
20//! writes: an omitted `version`, channels as plain strings, explicit `null` for
21//! absent optional fields, `*` and bare version literals as Python constraints,
22//! and a revision instead of an artifact digest for packages with a `source`.
23//! Unlike conda-lock, SHA256-only conda packages are accepted, as CEP-37 allows.
24//!
25//! # Comments and formatting
26//!
27//! Writing is canonical: packages and target platforms are sorted, maps use
28//! lexical key order, and comments are not preserved.
29//!
30//! # Errors
31//!
32//! Every failure is an [`ErrorKind`] plus the locations it applies to: the model
33//! path always, and the byte span in the original YAML whenever the diagnostic
34//! comes from a [`Document`]. Match on the kind; the rendered message is
35//! documentation, not API.
36//!
37//! ```
38//! use rattler_conda_lock::{Document, ErrorKind};
39//!
40//! let source = "\
41//! metadata:
42//!   content_hash:
43//!     linux-64: not-a-digest
44//!   channels: []
45//!   platforms: [linux-64]
46//!   sources: []
47//! package: []
48//! ";
49//! let error = Document::parse(source).unwrap_err();
50//!
51//! assert!(matches!(error.kind(), ErrorKind::InvalidDigest { length: 64 }));
52//! assert_eq!(error.path().as_str(), "metadata.content_hash.linux-64");
53//!
54//! // The span points into the text that was read, so a caller can render the
55//! // offending line itself, or let miette do it.
56//! assert_eq!(&source[error.span().unwrap()], "not-a-digest");
57//! assert_eq!(
58//!     error.to_string(),
59//!     "metadata.content_hash.linux-64: expected exactly 64 hexadecimal digits"
60//! );
61//! ```
62//!
63//! Diagnostics about two places carry both, which is what makes duplicate
64//! entries reviewable instead of merely rejected:
65//!
66//! ```
67//! use rattler_conda_lock::{Document, ErrorKind};
68//!
69//! let source = "\
70//! metadata:
71//!   content_hash:
72//!     linux-64: 8b7df143d91c716ecfa5fc1730022f6b421b05cedee8fd52b1fc65a96030ad52
73//!   channels: []
74//!   platforms: [linux-64, linux-64]
75//!   sources: []
76//! package: []
77//! ";
78//! let error = Document::parse(source).unwrap_err();
79//!
80//! assert!(matches!(error.kind(), ErrorKind::DuplicatePlatform));
81//! let [duplicate, first] = error.labels() else { panic!("expected two labels") };
82//! assert_eq!(first.message(), Some("first declared here"));
83//! assert!(duplicate.span().unwrap().start > first.span().unwrap().start);
84//! ```
